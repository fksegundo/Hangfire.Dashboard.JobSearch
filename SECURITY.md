# Security Policy

## Supported Versions

Only the latest published major/minor version of `Hangfire.Dashboard.JobSearch` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `Hangfire.Dashboard.JobSearch`, please do **NOT** open a public issue.

Instead, please send a responsible disclosure report directly via email or GitHub Private Vulnerability Reporting:
- Open an advisory at [GitHub Security Advisories](https://github.com/fksegundo/Hangfire.Dashboard.JobSearch/security/advisories)
- Or contact the maintainers directly via GitHub profile.

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof of concept.
3. Potential impact and attack vectors.

We will acknowledge receipt within 48 hours and work towards a fix promptly before public disclosure.
